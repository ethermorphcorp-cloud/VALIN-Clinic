## Feature

### ระบบผู้ใช้และสิทธิ์
- Login ด้วย username/password (hash + salt) และ session token เก็บใน CacheService อายุ 6 ชม.
- มี 2 ระดับคือ **admin** และ **staff** โดย Dashboard, ค่าใช้จ่าย & จัดซื้อ และตั้งค่าคลินิก ใช้ได้เฉพาะ admin
- ผู้ใช้เปลี่ยนรหัสผ่านเองได้ และ admin รีเซ็ตรหัสพนักงานได้
- บันทึกทุกการเปลี่ยนแปลงลง AuditLog

### เมนูหลัก
1. **Dashboard** (admin): รายได้รวม, ค่าใช้จ่าย, กำไร/%กำไร, จำนวนลูกค้า, รายได้ส่วนคลินิก/เซลล์/แพทย์, แนวโน้มรายเดือน, กราฟรายได้แยกตามประเภท แพทย์ เซลล์ และโปรโมชัน, ค่าใช้จ่ายแยกหมวด เลือกช่วงวันที่ได้ และ cache ผลไว้ (ล้างอัตโนมัติด้วย version bump ทุกครั้งที่มีการบันทึก)
2. **ข้อมูลคนไข้**: ประวัติ (ชื่อ, ชื่อเล่น, เบอร์, วันเกิด, เพศ, อีเมล, รูป), รัน HN อัตโนมัติ, ค้นหาพร้อม autocomplete, หน้าโปรไฟล์ที่รวมประวัติการรักษา
3. **บันทึกการรักษา**:
   - เลือกคนไข้, หมวดบริการ, แพทย์, เซลล์ และวิธีชำระเงิน
   - เบิกเวชภัณฑ์จากสต๊อก (ตัดสต๊อกอัตโนมัติ) และ Canula
   - รายการโปร, รายการยา/สินค้าเพิ่ม และรายการอื่นๆ เพิ่มได้หลายบรรทัด
   - **คำนวณส่วนแบ่งอัตโนมัติ** ให้เซลล์ (%คอมมิชชัน), แพทย์ (% + %ส่วนแบ่งของแต่ละโปร + เติมยอดขั้นต่ำรายวัน) และคลินิก พร้อมยอดที่ต้องจ่าย supplier
   - สถานะการจ่ายเงิน และสถานะนัดหมาย/เสร็จสิ้น
   - แนบรูป OPD ซึ่งเก็บใน Drive แยกโฟลเดอร์ ปี/เดือน/วัน
   - มีมุมมองรายการและมุมมองปฏิทินรายเดือน พร้อมสรุปยอดรายวัน
   - **ออกใบเสร็จ** โดยรันเลขที่อัตโนมัติ และเปิดหน้าพิมพ์ผ่าน ticket ที่ใช้ได้ครั้งเดียวภายใน 5 นาที
4. **จัดการสต๊อก**: รายการเวชภัณฑ์/สินค้า, อัพเดตสต๊อกทีละหลายรายการ (รับเข้า/คงเหลือ), ประวัติการเคลื่อนไหวต่อรายการซึ่งแก้ไขหรือลบได้ และเรียงตามวันอัพเดตล่าสุด
5. **ค่าใช้จ่าย & จัดซื้อ** (admin): บันทึกค่าใช้จ่ายแยกหมวด และใบสั่งซื้อ (PO) ที่มีหลายรายการต่อ supplier
6. **จัดการโปรโมชันหน้าคลินิก**: ชื่อโปร, ราคา, %ส่วนแบ่งแพทย์ (ส่วนคลินิกคำนวณเป็น 100 − %แพทย์) และเปิด/ปิดใช้งาน
7. **ตั้งค่าคลินิก** (admin): แพทย์/เซลล์ (%คอมมิชชัน, ยอดขั้นต่ำ), หมวดหมู่ (การรักษา/สต๊อก/ค่าใช้จ่าย), ข้อมูลบริษัท (ชื่อ, ที่อยู่, เบอร์, เลขผู้เสียภาษี, โลโก้, รูปหน้า login) และพนักงาน (สิทธิ์, LINE ID)

### LINE Messaging API
- ปุ่ม **ส่งข้อมูลไป LINE** ส่งสรุปยอดรายวันให้ admin ทุกคนที่กรอก LINE ID ไว้
- ตั้ง trigger ส่งสรุปยอดอัตโนมัติทุกวันตามเวลาที่กำหนดได้
- Chatbot ผ่าน webhook (`doPost`) รองรับคำสั่งเหล่านี้ โดยตรวจสิทธิ์จาก LINE ID ของพนักงานที่ Active
  - `Line ID ของฉัน` ตอบกลับ LINE user id ของผู้ส่ง
  - `สรุปยอดวันนี้`
  - `สรุปยอดวันอื่น [yyyy-MM]` แสดงปฏิทินให้กดเลือกวัน
  - `สรุปยอดวันที่ yyyy-MM-dd`

### อื่นๆ
- อัปโหลดไฟล์ใหญ่แบบ resumable chunk ผ่าน server โดยไม่ส่ง OAuth token ไปที่ client
- Cache master data และรายการ autocomplete ของคนไข้/สต๊อกเพื่อลดการอ่าน Sheet
- `seedDemoData` สำหรับใส่ข้อมูลตัวอย่าง

## ฐานข้อมูล (Google Sheets)

Patients, Records, Stock, StockLog, Expenses, Orders, OrderLines, Doctors, Sales, Promotions, Categories, Staff, ClinicSettings, Counters, AuditLog โดยโครงสร้างคอลัมน์ที่ใช้งานจริงอยู่ที่ `CONFIG.HEADERS` ใน `Code.js`

## การติดตั้ง

1. รัน `setupProject` จาก Apps Script editor เพื่อสร้าง Spreadsheet, ทุก sheet, โฟลเดอร์ใน Drive และบัญชี admin เริ่มต้น
2. (ไม่บังคับ) รัน `seedDemoData` เพื่อใส่ข้อมูลตัวอย่าง
3. Deploy เป็น Web app
4. ตั้ง Script Property `LINE_CHANNEL_ACCESS_TOKEN`
5. (ไม่บังคับ) สร้าง deployment แยกอีกตัวสำหรับ LINE Webhook URL โดยทุกครั้งที่อัปเดตโค้ดต้องเลือกเวอร์ชันใหม่ให้ทั้งสอง deployment

> ⚠️ บัญชี admin เริ่มต้นคือ `admin` / `12345` ควรเปลี่ยนรหัสทันทีหลังติดตั้ง
