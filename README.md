## Feature

### ระบบผู้ใช้และสิทธิ์
- Login ด้วย username/password (hash + salt) และ session token เก็บใน CacheService อายุ 6 ชม.
- มี 2 ระดับคือ **admin** และ **staff** โดย Dashboard, รายงาน, ค่าใช้จ่าย & จัดซื้อ และตั้งค่าคลินิก ใช้ได้เฉพาะ admin
- ผู้ใช้เปลี่ยนรหัสผ่านเองได้ และ admin รีเซ็ตรหัสพนักงานได้
- บันทึกทุกการเปลี่ยนแปลงลง AuditLog

### Flow การทำงาน
สร้างประวัติคนไข้ → จัดยา-เบิกยา → บันทึกการรักษา (เวชภัณฑ์, หัตถการ, ยา, รายการอื่นๆ — เบิกยาเพิ่มได้) → ชำระเงิน

### เมนูหลัก
1. **Dashboard** (admin): รายได้รวม, ค่าใช้จ่าย, กำไร/%กำไร, จำนวนลูกค้า, รายได้ส่วนคลินิก/เซลล์/แพทย์, แนวโน้มรายเดือน, กราฟรายได้แยกตามประเภท แพทย์ เซลล์ และโปรโมชัน, ค่าใช้จ่ายแยกหมวด เลือกช่วงวันที่ได้ และ cache ผลไว้ (ล้างอัตโนมัติด้วย version bump ทุกครั้งที่มีการบันทึก)
2. **ข้อมูลคนไข้**: ประวัติ (เลข HN ที่กรอกเอง ห้ามซ้ำ, ชื่อ, ชื่อเล่น, เบอร์, วันเกิด, เพศ, อีเมล, รูป) และรหัสระบบที่รันอัตโนมัติ, ค้นหาด้วยชื่อ/เบอร์/HN, หน้าโปรไฟล์ที่รวมประวัติการรักษาและยาฝาก
3. **จัดยา-เบิกยา**: เบิกยาจากสต๊อกให้คนไข้ (เลือกเซลล์, ตัดสต๊อกทันที, เก็บราคาทุนและราคาขายตามขั้นราคา) แต่ละรายการมีสถานะ "รอบันทึกการรักษา" จนกว่าบันทึกการรักษาของคนไข้จะคิดเงินรายการนั้น
4. **บันทึกการรักษา**:
   - เลือกคนไข้ และเซลล์ สถานะการรักษา: จัดยาแล้ว → เสร็จสิ้น (กดปุ่ม "บันทึกการรักษาเสร็จสิ้น"; "บันทึกร่าง" ยังเป็นจัดยาแล้ว)
   - 1 เวชภัณฑ์ (ตัดสต๊อก) · 2 หัตถการ (เลือกแพทย์และหัตถการต่อบรรทัด — คนไข้ 1 คนทำกับแพทย์หลายคนได้, ยอดรวม = จำนวนเงินหัตถการ) · 3 ยา: รายการยาจากใบเบิก (ดึงอัตโนมัติ, ระบุจำนวนที่ใช้/ฝาก และวันหมดอายุ, ไม่คิดเงินในยอดรับชำระ) และรายการยาเบิกเพิ่ม (ตัดสต๊อก, คิดราคาขาย); ใช้ยาฝาก, ถือยาเข้า, Messenger · 4 รายการอื่นๆ (โปรหน้าคลีนิค เลือกแพทย์ต่อบรรทัด, Canula, อื่นๆ)
   - **คำนวณส่วนแบ่งอัตโนมัติ** ให้เซลล์ (%คอมมิชชัน), แพทย์แต่ละคน (% ของหัตถการที่ทำ + %ส่วนแบ่งของแต่ละโปร + เติมยอดขั้นต่ำรายวันแยกรายแพทย์) และคลินิก (ส่วนที่เหลือทั้งหมด รวมค่ายาเบิกเพิ่มและรายการอื่นๆ — ไม่มีส่วนแบ่ง supplier) รายละเอียดยอดรับชำระไม่แสดงแถวที่เป็น 0
   - **ชำระเงิน** เป็นขั้นตอนสุดท้าย (ปุ่ม "บันทึกและชำระเงิน" หรือปุ่มชำระเงินในรายการ): สรุปยอด, วิธีชำระเงิน, สถานะ และพิมพ์ใบเสร็จ
   - แนบรูป OPD ซึ่งเก็บใน Drive แยกโฟลเดอร์ ปี/เดือน/วัน
   - มีมุมมองรายการและมุมมองปฏิทินรายเดือน พร้อมสรุปยอดรายวัน
   - **ออกใบเสร็จ** โดยรันเลขที่อัตโนมัติ และเปิดหน้าพิมพ์ผ่าน ticket ที่ใช้ได้ครั้งเดียวภายใน 5 นาที
5. **รายการยาฝาก**: ยาฝากทุกคนไข้แยกเป็นล็อต (จำนวนคงเหลือ, วันหมดอายุ, บันทึกการรักษาที่มา) กรองใกล้หมดอายุ/หมดอายุแล้ว แก้วันหมดอายุได้ และ admin แก้จำนวนได้ การใช้ยาฝากตัดล็อตที่หมดอายุก่อน (ไม่ตัดล็อตที่หมดอายุแล้ว)
6. **รายงาน** (admin): เลือกช่วงวันที่และชื่อเซลล์ ดาวน์โหลด PDF ได้
   - รายงานรายวัน: วันที่, ชื่อคนไข้, ชื่อเซลล์, รายละเอียดตามใบเสร็จ, จำนวนเงิน
   - รายงานรายเซลล์: วันที่, ชื่อคนไข้, ชื่อเซลล์, รายการยา, จำนวน, ราคาทุน/หน่วย, จำนวนเงิน (ทุน), ราคาขาย/หน่วย, จำนวนเงิน (ราคาขาย), ส่วนต่างสุทธิ, หมายเหตุ — รวมยาจากใบเบิกทุกรายการ (ราคาขายตามขั้นราคา ณ วันเบิก) และยาเบิกเพิ่ม (หมายเหตุระบุบันทึกการรักษาที่เบิกเพิ่ม)
7. **จัดการสินค้า/บริการ**: รายการเวชภัณฑ์ และรายการยา (สต๊อก, อัพเดตสต๊อก, ประวัติการเคลื่อนไหว, นำเข้า CSV) และรายการหัตถการ (ชื่อ, หมวดหมู่, ราคา, เปิด/ปิดใช้งาน — admin แก้ไข)
8. **ค่าใช้จ่าย & จัดซื้อ** (admin): บันทึกค่าใช้จ่ายแยกหมวด และใบสั่งซื้อ (PO) ที่มีหลายรายการต่อ supplier
9. **จัดการโปรโมชันหน้าคลินิก**: ชื่อโปร, ราคา, %ส่วนแบ่งแพทย์ (ส่วนคลินิกคำนวณเป็น 100 − %แพทย์) และเปิด/ปิดใช้งาน
10. **ตั้งค่าคลินิก** (admin): แพทย์/เซลล์ (%คอมมิชชัน, ยอดขั้นต่ำ), หมวดหมู่ (สินค้า/หัตถการ/ค่าใช้จ่าย), ข้อมูลบริษัท (ชื่อ, ที่อยู่, เบอร์, เลขผู้เสียภาษี, โลโก้, รูปหน้า login) และพนักงาน (สิทธิ์, LINE ID)

### LINE Messaging API
- ปุ่ม **ส่งข้อมูลไป LINE** ส่งสรุปยอดรายวันให้ admin ทุกคนที่กรอก LINE ID ไว้
- ตั้ง trigger ส่งสรุปยอดอัตโนมัติทุกวันตามเวลาที่กำหนดได้
- Chatbot ผ่าน webhook (`doPost`) รองรับคำสั่งเหล่านี้ โดยตรวจสิทธิ์จาก LINE ID ของพนักงานที่ Active
  - `Line ID ของฉัน` ตอบกลับ LINE user id ของผู้ส่ง
  - `สรุปยอดวันนี้`
  - `สรุปยอดวันอื่น [yyyy-MM]` แสดงปฏิทินให้กดเลือกวัน
  - `สรุปยอดวันที่ yyyy-MM-dd`

## การติดตั้ง

1. รัน `setupProject` จาก Apps Script editor เพื่อสร้าง Spreadsheet, ทุก sheet, โฟลเดอร์ใน Drive และบัญชี admin เริ่มต้น
2. (ไม่บังคับ) รัน `seedDemoData` เพื่อใส่ข้อมูลตัวอย่าง

5. (ไม่บังคับ) สร้าง deployment แยกอีกตัวสำหรับ LINE Webhook URL โดยทุกครั้งที่อัปเดตโค้ดต้องเลือกเวอร์ชันใหม่ให้ทั้งสอง deployment

> ⚠️ บัญชี admin เริ่มต้นคือ `admin` / `12345` ควรเปลี่ยนรหัสทันทีหลังติดตั้ง
