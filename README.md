## Feature

### ระบบผู้ใช้และสิทธิ์
- Login ด้วย username/password (hash + salt) และ session token เก็บใน CacheService อายุ 6 ชม.
- มี 2 ระดับคือ **admin** และ **staff** โดย Dashboard, รายงาน, ค่าใช้จ่าย & จัดซื้อ และตั้งค่าคลินิก ใช้ได้เฉพาะ admin
- ผู้ใช้เปลี่ยนรหัสผ่านเองได้ และ admin รีเซ็ตรหัสพนักงานได้
- บันทึกทุกการเปลี่ยนแปลงลง AuditLog

### Flow การทำงาน
สร้างประวัติคนไข้ → จัดยา-เบิกยา → บันทึกการรักษา (เวชภัณฑ์, หัตถการ, ยา, รายการอื่นๆ — เบิกยาเพิ่มได้) → ชำระเงิน

### เมนูหลัก
1. **Dashboard** (admin): **รายได้** = ที่เก็บจากลูกค้า (หัตถการ, โปร, Canula, อื่นๆ — เฉพาะบันทึกที่ชำระแล้ว) + ที่เก็บจากเซลล์ (รายงานรายเซลล์ ณ ราคาทุน); **รายจ่าย** = ค่าใช้จ่าย + จัดซื้อ + ส่วนแบ่งแพทย์ + ส่วนแบ่งเซลล์; กำไร = รายได้ − รายจ่าย. การ์ด: รายได้รวม, รายจ่ายรวม, กำไร (พร้อม %กำไร), จำนวนคนไข้; กราฟ: รายเดือน (แสดงเฉพาะเดือนที่มีข้อมูล) → รายได้รายหมวดหมู่ (รวมกันเท่ากับรายได้รวม) + รายจ่ายรายหมวดหมู่ (รวมกันเท่ากับรายจ่ายรวม) → สัดส่วนส่วนแบ่งแพทย์ / ส่วนแบ่งเซลล์ / รายได้รายโปรโมชัน เลือกช่วงวันที่ได้ และ cache ผลไว้ (ล้างอัตโนมัติด้วย version bump ทุกครั้งที่มีการบันทึก)
2. **ข้อมูลคนไข้**: ประวัติ (เลข HN ที่กรอกเอง ห้ามซ้ำ, ชื่อ, ชื่อเล่น, เบอร์, วันเกิด, เพศ, อีเมล, รูป) และรหัสระบบที่รันอัตโนมัติ, ค้นหาด้วยชื่อ/เบอร์/HN, หน้าโปรไฟล์ที่รวมประวัติการรักษาและยาฝาก
3. **จัดยา-เบิกยา**: เบิกยาจากสต๊อกให้คนไข้ (เลือกเซลล์, ตัดสต๊อกทันที, เก็บราคาทุน — ไม่มีราคาขาย เพราะลูกค้าจ่ายค่ายาให้เซลล์โดยตรง) เมื่อบันทึกการเบิก ระบบสร้างบันทึกการรักษา (สถานะ **จัดยาแล้ว**) ให้ทันที; รายการที่บันทึกพร้อมกันแสดงเป็นกลุ่มเดียว (HN, ชื่อคนไข้, เซลล์, สถานะ รวมแถว แยกแถวเฉพาะยา/จำนวน/ราคา) ค้นหาด้วยชื่อ/เบอร์/HN กรองตามสถานะการรักษา (เริ่มต้น = จัดยาแล้ว; เลือกเสร็จสิ้น/ทั้งหมดได้) แนบรูปยาที่เบิกได้สูงสุด 8 รูปต่อการเบิก (ตอนสร้างรายการ หรือภายหลังจากเมนู "จัดการ" > รูปยาที่เบิก — เพิ่ม/ลบได้ทั้ง admin และ staff; ย่อรูปก่อนอัปโหลด เก็บใน Drive โฟลเดอร์ปี/เดือน/วันเดียวกับรูป OPD) และมีเมนู "จัดการ" (ไปที่บันทึกการรักษา, รูปยาที่เบิก, ลบรายการยา — admin)
4. **บันทึกการรักษา**:
   - เลือกคนไข้ และเซลล์ เปิดบันทึกที่ "จัดยาแล้ว" มาเพิ่มหัตถการ/รายการอื่นๆ (หรือเพิ่มบันทึกใหม่เองก็ได้) สถานะการรักษา: จัดยาแล้ว → เสร็จสิ้น (กดปุ่ม "บันทึกการรักษาเสร็จสิ้น"; "บันทึกร่าง" ยังเป็นจัดยาแล้ว)
   - 1 เวชภัณฑ์ (ตัดสต๊อก) · 2 หัตถการ (เลือกแพทย์และหัตถการต่อบรรทัด — คนไข้ 1 คนทำกับแพทย์หลายคนได้, ยอดรวม = จำนวนเงินหัตถการ) · 3 ยา: รายการยาจากใบเบิก (ดึงอัตโนมัติ, ระบุจำนวนที่ใช้/ฝาก และวันหมดอายุ, ไม่คิดเงินในยอดรับชำระ) และรายการยาเบิกเพิ่ม (ตัดสต๊อก, ไม่คิดเงิน — ลูกค้าจ่ายค่ายาให้เซลล์โดยตรง; ต้นทุนไปอยู่ในรายงานรายเซลล์พร้อมหมายเหตุ เบิกเพิ่ม); ใช้ยาฝาก, ถือยาเข้า, Messenger · 4 รายการอื่นๆ (โปรหน้าคลีนิค เลือกแพทย์ต่อบรรทัด, Canula, อื่นๆ)
   - **คำนวณส่วนแบ่งอัตโนมัติ** ให้เซลล์ (%คอมมิชชัน), แพทย์แต่ละคน (% ของหัตถการที่ทำ + %ส่วนแบ่งของแต่ละโปร + เติมยอดขั้นต่ำรายวันแยกรายแพทย์) และคลินิก (ส่วนที่เหลือทั้งหมด รวมรายการอื่นๆ — ยาเบิกเพิ่มไม่คิดเงิน และไม่มีส่วนแบ่ง supplier) รายละเอียดยอดรับชำระไม่แสดงแถวที่เป็น 0
   - **ชำระเงิน** เป็นขั้นตอนสุดท้าย (ปุ่ม "บันทึกและชำระเงิน" หรือปุ่มชำระเงินในรายการ): สรุปยอด, วิธีชำระเงิน, สถานะ และพิมพ์ใบเสร็จ
   - แนบรูป OPD ซึ่งเก็บใน Drive แยกโฟลเดอร์ ปี/เดือน/วัน
   - มีมุมมองรายการและมุมมองปฏิทินรายเดือน (สีตามสถานะการรักษา: จัดยาแล้ว / เสร็จสิ้น) พร้อมสรุปยอดรายวัน; ตารางรายการแสดง HN และสถานะการรักษา (ตัวกรองเริ่มต้น = จัดยาแล้ว) ค้นหาด้วยชื่อ/เบอร์/HN คลิกแถวเพื่อดูรายละเอียดที่แผงด้านขวา และมีเมนู "จัดการ" (ชำระเงิน, พิมพ์ใบเสร็จ, แก้ไข, ลบ)
   - **พิมพ์ใบเสร็จ** รันเลขที่อัตโนมัติ แล้วแสดงตัวอย่างใบเสร็จในหน้าต่างพรีวิว (กรอบ A4) พร้อมปุ่ม พิมพ์ / บันทึกเป็น PDF / ปิด (ไม่แสดงกลุ่มค่ายาเมื่อไม่มียอด); หน้า `?page=receipt&ticket=...` ยังใช้เปิดแบบหน้าเดี่ยวได้ (ticket ใช้ได้ครั้งเดียวภายใน 5 นาที)
5. **รายการยาฝาก**: ยาฝากทุกคนไข้แยกเป็นล็อต (จำนวนคงเหลือ, วันหมดอายุ, บันทึกการรักษาที่มา) กรองใกล้หมดอายุ/หมดอายุแล้ว แก้วันหมดอายุได้ และ admin แก้จำนวนได้ การใช้ยาฝากตัดล็อตที่หมดอายุก่อน (ไม่ตัดล็อตที่หมดอายุแล้ว) คลิกรายการเพื่อดูสรุปและความเคลื่อนไหว (ฝาก / ใช้ / ปรับยอด วันที่ และยอดเปลี่ยนแปลง) ที่แผงด้านขวา
6. **รายงาน** (admin): เลือกช่วงวันที่และชื่อเซลล์ ดาวน์โหลด PDF ได้
   - รายงานรายวัน: วันที่, ชื่อคนไข้, ชื่อเซลล์, รายละเอียดตามใบเสร็จ, จำนวนเงิน
   - รายงานรายเซลล์: รายได้ที่คลินิกเก็บจากเซลล์ ณ ราคาทุน (ไม่มีราคาขาย) แสดงแบบ pivot — วันที่ > ชื่อเซลล์ > ชื่อคนไข้ > รายการยา (จำนวน, ราคาทุน/หน่วย, จำนวนเงิน, หมายเหตุรายการเบิกเพิ่ม) พร้อมยอดรวมต่อเซลล์/วัน และสรุปยอดแต่ละเซลล์; คลิกแถวเพื่อดูตัวอย่างและดาวน์โหลด PDF ของเซลล์/วันนั้น
7. **จัดการสินค้า/บริการ**: รายการเวชภัณฑ์ และรายการยา (สต๊อก, อัพเดตสต๊อก, ประวัติการเคลื่อนไหว, นำเข้า CSV) และรายการหัตถการ (ชื่อ, หมวดหมู่, ราคา, เปิด/ปิดใช้งาน — admin แก้ไข)
8. **ค่าใช้จ่าย & จัดซื้อ** (admin): บันทึกค่าใช้จ่ายแยกหมวด และใบสั่งซื้อ (PO) ที่มีหลายรายการต่อ supplier — คลิกแถวใน "จัดซื้อ" เพื่อดูรายละเอียด (สรุป + รายการสินค้า) ที่แผงด้านขวา แล้วกดแก้ไขต่อได้
9. **จัดการโปรโมชันหน้าคลินิก**: ชื่อโปร, ราคา, %ส่วนแบ่งแพทย์ (ส่วนคลินิกคำนวณเป็น 100 − %แพทย์) และเปิด/ปิดใช้งาน
10. **ตั้งค่าคลินิก** (admin): แพทย์/เซลล์ (%คอมมิชชัน, ยอดขั้นต่ำ), หมวดหมู่ (สินค้า/หัตถการ/ค่าใช้จ่าย), ข้อมูลบริษัท (ชื่อ, ที่อยู่, เบอร์, เลขผู้เสียภาษี, โลโก้, รูปหน้า login) และพนักงาน (สิทธิ์, LINE ID)

### LINE Messaging API
- ปุ่ม **ส่งข้อมูลไป LINE** ส่งสรุปยอดรายวันให้ admin ทุกคนที่กรอก LINE ID ไว้
- ตั้ง trigger ส่งสรุปยอดอัตโนมัติทุกวันตามเวลาที่กำหนดได้
- Chatbot ผ่าน webhook (`doPost`) รองรับคำสั่งเหล่านี้ โดยตรวจสิทธิ์จาก LINE ID ของพนักงานที่ Active
  - `Line ID ของฉัน` ตอบกลับ LINE user id ของผู้ส่ง
  - `สรุปยอดวันนี้`
  - `สรุปยอดวันอื่น [yyyy-MM]` แสดงปฏิทินให้กดเลือกวัน
  - `สรุปยอดวันที่ yyyy-MM-dd`
